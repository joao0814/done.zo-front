# Done.zo Front 🚀

Interface web para gerenciamento de tarefas, desenvolvida com React, TypeScript e TailwindCSS.

Este projeto consome uma API REST construída com Node.js + PostgreSQL e representa a camada frontend da aplicação.

---

## 📌 Objetivo

Construir uma aplicação frontend moderna e escalável para gerenciamento de tarefas, aplicando boas práticas de:

- Componentização
- Tipagem com TypeScript
- Consumo de APIs REST
- Organização de código
- Estilização com TailwindCSS

---

## 🛠️ Tecnologias Utilizadas

- React
- TypeScript
- TailwindCSS
- Axios

## Testes

O projeto usa Vitest com Testing Library para testes de componentes.

- Rodar em modo watch: `npm test`
- Rodar uma vez: `npm run test:run`
